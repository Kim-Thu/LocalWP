# LocalWP

LocalWP là ứng dụng desktop quản lý môi trường phát triển WordPress cục bộ bằng Docker Compose.

## Trạng thái

Dự án đang ở giai đoạn **pre-alpha**, tập trung dựng nền tảng kiến trúc, CI/CD và quy trình phát triển trước khi triển khai các module runtime.

## Stack chính

- C# và .NET 8
- Avalonia UI
- MVVM
- Docker Compose v2
- Nginx
- PHP-FPM
- MySQL hoặc MariaDB
- WP-CLI

## Phạm vi MVP

MVP nhắm Windows 10/11 x64 và sẽ hỗ trợ tạo, chạy, dừng, clone, import, backup và cập nhật nhiều site WordPress với domain và SSL cục bộ.
